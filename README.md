# Studio Japi Arquitetura Contemporânea — Jundiaí/SP

Landing page institucional de alto padrão para demonstração de projetos de arquitetura residencial unifamiliar contemporânea em condomínios fechados da região de Jundiaí - SP (Fazenda Serrazul, Reserva da Serra, Quinta das Paineiras, Bosque dos Jatobás, Malota).

## 🏛️ Destaques do Projeto

- **Direção de Arte Editorial**: Paleta orgânica de luxo inspirada na Serra do Japi (alabastro, madeira nobre, concreto aparente e verde mata atlântica) com tipografia refinada.
- **Simulador Interativo de Viabilidade de Obra**: Cálculo dinâmico por metragem, topografia do lote, quantidade de suítes e comodidades de luxo (piscina infinita, adega subterrânea, gourmet, cinema).
- **Slider Antes & Depois**: Comparador interativo entre maquete 3D fotorrealista e fotografia da obra concluída, reforçando o valor de fidelidade construtiva.
- **Galeria de Cases com Modal Imersivo**: Projetos autorais com fichas técnicas, desafios topográficos e carrossel de fotos em alta definição.
- **Linha do Tempo em 5 Etapas**: Metodologia de trabalho desde o estudo topoclimático até a assessoria técnica no canteiro.
- **Formulário de Diagnóstico de Terreno**: Captação de leads qualificados integrada diretamente com formatação pronta para o WhatsApp VIP.
- **100% Responsivo**: Otimizado para smartphones, tablets e telas 4K.

## 🚀 Como Rodar Localmente

1. Clone ou acerte o diretório:
   ```bash
   cd demo-arquitetura
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Acesse no navegador:
   ```
   http://localhost:3000
   ```

## 📦 Deploy na Vercel

O projeto foi construído sobre o **Next.js 14 (App Router)** com **Tailwind CSS**. Para realizar o deploy na Vercel:
1. Conecte o repositório no dashboard da [Vercel](https://vercel.com).
2. O framework preset será detectado automaticamente como **Next.js**.
3. Clique em **Deploy**.
